01

Why Donut

Traditional extraction often chains OCR, layout analysis and field rules. Donut treats the task as image-to-sequence generation and emits structured tokens directly.

02

Pipeline

The repository covers preprocessing, target sequence generation, training, checkpointing, early stopping, mixed precision, single/batch inference and a lightweight browser client.

03

API delivery

The FastAPI layer supports structured JSON responses and keeps model inference separated from the training code.

04

Evaluation honesty

The public repository intentionally does not claim accuracy/F1 until a reproducible held-out evaluation report is versioned. Training metrics are not presented as production quality.
